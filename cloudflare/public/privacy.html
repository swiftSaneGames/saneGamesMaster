Privacy & access

This dashboard serves the SaneGames studio team. It does not provide public account registration.

Google sign-in

We request your Google account identifier, verified email address, and basic profile name to authenticate you. Only explicitly approved accounts can access the workspace. Google passwords never pass through this application. Google access tokens are not retained.

Stored data

The application stores sessions, account-to-identity bindings, project records, tasks, research shortlists, release manifests, and an activity log in Cloudflare-hosted storage. Session cookies expire after one hour. Expired session records are removed during subsequent requests.

Release approvals

Approval records identify the reviewing account and exact build manifest. Approval is not a store upload. Store publishing and development-agent execution are separate integrations.

Access and removal

Ask the studio administrator for data export or removal. Remove an account from the server allowlist to revoke its access. Account deletion and full database recovery are administrator operations, not public endpoints.

No advertising or analytics trackers are installed in this dashboard.
